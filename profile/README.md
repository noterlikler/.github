## NOTERLİKLER hakkında

NOTERLİKLER, Türkiye genelindeki noterliklerin adres, telefon, çalışma saatleri ve yol tarifi bilgilerini bir araya getiren bir rehber platformudur. Aradığınız noterliği il, ilçe veya noterlik adıyla bulabilir; yayınlanan tarihlere ait nöbetçi noter listelerini inceleyebilirsiniz.

Projeyi, noterlik bilgilerine ulaşmayı ve işlem öncesi hazırlığı kolaylaştırmak amacıyla geliştirdim. Web sitesi, tarayıcı eklentileri, WordPress eklentisi ve farklı sitelere eklenebilen widget üzerinden aynı rehbere erişim sağlıyorum.

## Platformda neler var?

| Özellik | Kullanım |
| --- | --- |
| Noterlik araması | İl, ilçe veya noterlik adıyla arama ve sonuç önerileri |
| Noter detayları | Adres, telefon, çalışma saatleri, harita ve yol tarifi |
| Tarihli nöbet listeleri | Yayınlanan nöbet tarihine göre il ve ilçe sorgulaması |
| Hafta sonu sayfaları | Cumartesi ve pazar günü nöbetçi noter listeleri |
| İşlem rehberleri | Araç satışı, vekâletname, tercüme, apostil ve diğer başvurulara hazırlık |
| Mobil kullanım | Mobil ve masaüstü ekranlara uyumlu web arayüzü ve PWA |

## Teknoloji altyapısı

Web uygulaması, **PHP tabanlı Laravel framework’ü** ile geliştirilmiştir. Arayüzde HTML, CSS ve JavaScript kullanılır. Uygulamalar ve eklentiler, noterlik bilgilerine erişmek için platformun API altyapısından yararlanır.

| Bileşen | Teknoloji / yaklaşım |
| --- | --- |
| Web uygulaması | PHP ve Laravel |
| Arayüz | HTML, CSS ve JavaScript |
| Veri erişimi | API üzerinden noterlik ve tarih bazlı nöbet verileri |
| ChatGPT bağlantısı | Laravel MCP entegrasyonu |
| Farklı ekranlar | Responsive tasarım ve PWA |

Geliştirmede anlaşılır arayüzlere, gereksiz indirme yükünü azaltmaya ve eklentilerin eklendikleri sitelerle uyumlu çalışmasına önem veriyorum.
